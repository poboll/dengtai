# Docker Desktop替代方案盘点：OrbStack vs Podman

## 为什么要替代

Docker Desktop 存在以下痛点：内存占用大（4-8GB）、CPU 使用率高、启动速度慢、商业许可费用、macOS 文件系统性能差。

## OrbStack

macOS 上最受欢迎的 Docker Desktop 替代方案：

| 指标 | Docker Desktop | OrbStack |
|------|---------------|----------|
| 内存占用 | 4-8 GB | 0.5-2 GB |
| 启动时间 | 30-60 秒 | 2-5 秒 |
| CPU 空闲 | 5-15% | < 1% |
| 文件系统 | 慢 | 接近原生 |

核心功能：完全兼容 Docker CLI、内置 K8s、Linux VM 管理、自动域名解析。

个人使用免费，团队 $8/用户/月。

## Podman

红帽推出的开源容器工具：
- **无守护进程**：不需要 root 权限运行
- **完全开源**：Apache 2.0 许可
- **兼容 Docker**：支持 Dockerfile 和大部分 Docker 命令
- **Rootless 容器**：更安全

适用场景：Linux 服务器（原生支持最好）、安全敏感环境、CI/CD 流水线。

## 使用建议

- **macOS 开发者** → OrbStack（体验最好）
- **Linux 服务器** → Podman（最原生）
- **Windows 开发者** → Docker Desktop 或 WSL2 + Podman

## 迁移指南

从 Docker Desktop 迁移到 OrbStack 只需：安装 OrbStack → 导入 Docker 数据 → 自动完成。
