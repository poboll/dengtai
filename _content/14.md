# Google VP警告：LLM包装类创业公司没有未来

## 警告内容

Google Cloud AI 副总裁在 TechCrunch Disrupt 2026 大会上表示，仅��大模型之上做简单包装的创业公司将面临生存危机。

## 核心论点

### 1. API 价格持续下降

大模型 API 价格在过去一年下降了 90%。当基础能力变得廉价，简单包装的附加值趋近于零。

### 2. 模型能力不断增强

随着模型变得更智能，许多中间层工具将被模型原生能力取代：
- Prompt 优化工具 → 模型自身优化能力提升
- RAG 中间件 → 模型原生支持长上下文
- 输出格式化工具 → 模型原生结构化输出

### 3. 平台公司入场

Google、Microsoft、Amazon 正在将 AI 能力直接集成到现有产品中，压缩第三方工具的生存空间。

## 什么样的 AI 创业有未来

### 有护城河的方向

- **垂直领域数据**：拥有独特的行业数据集
- **工作流深度整合**：深入业务流程不可替代
- **硬件+AI**：机器人、IoT、边缘设备
- **合规与安全**：行业特定的合规解决方案
