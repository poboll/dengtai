# React 20发布：Server Components成为默认范式

## 里程碑发布

React 20 正式发布，Server Components 从实验性功能升级为默认推荐范式，标志着前端开发迎来最大的范式转变。

## 核心变化

### Server Components 默认化

React 20 中所有组件默认为 Server Components。需要客户端交互的组件使用 `use client` 指令标记。这意味着大部分组件在服务端渲染，只有需要交互的部分发送到客户端。

### React Compiler 正式版

React Compiler 不再需要手动 memo 化：
- 自动 memo 化所有组件和回调
- 消除不必要的重渲染
- 编译时优化比运行时优化快 3-5 倍

### 新的数据获取模式

内置 `use()` Hook 支持异步数据获取：
- 自动处理加载和错误状态
- 支持流式渲染
- 与 Suspense 深度集成

## 性能改进

| 指标 | React 19 | React 20 | 改进 |
|------|---------|---------|------|
| 首次加载 JS | 85KB | 42KB | -51% |
| LCP | 2.1s | 0.8s | -62% |
| INP | 180ms | 65ms | -64% |
| 内存占用 | 12MB | 6MB | -50% |

## 迁移指南

React 团队提供了 codemod 工具，可以自动将现有项目迁移到 React 20 模式。大部分项目的迁移可以在几小时内完成。

## 生态系统

Next.js 15、Remix 3 已全面支持 React 20。Material UI、Ant Design、shadcn/ui 也已发布兼容版本。
